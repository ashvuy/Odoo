How It Works

  1. Install Module: Add PerfectAI Branding to your Odoo instance
  2. Create Tenant Database: Set up a database for each client
  3. Configure Branding: Upload logos, set colors, customize text
  4. Apply Settings: One-click apply branding to tenant
  5. Deploy: Your clients see fully branded interface

Architecture

PerfectAI uses Odoo's native multi-database architecture:

  • Database-per-Tenant: Each client has isolated database
  • Independent Branding: Each database has unique branding
  • Secure Isolation: Complete data separation between tenants
  • Scalable: Add unlimited tenants without performance impact
